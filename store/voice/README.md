# Recording the voice for ABCD by Kirti

The app speaks with the phone's built-in voice until real recordings are added. Every
recording you add replaces that robot voice for the sentences it completes.

## The two scripts

| File | Language | Lines |
|---|---|---|
| `recording-script-en.tsv` | English | ~335 |
| `recording-script-hi.tsv` | Hindi | ~750 (370 of them are बारहखड़ी syllables) |

Open them in Excel or Google Sheets. Each line has:

- **FILE** – the name to save the recording as, e.g. `en_c7bf17e9`
- **SAY THIS** – exactly what to say, e.g. `Great job!`
- **SECTION** – where it's used

**Record from the top down.** "Everyday phrases" come first because each one is used in
dozens of sentences. A sentence switches to your voice only when *every* part of it is
recorded, so finishing the everyday phrases plus one section (for example "English") makes
that whole section sound human.

## How to record

1. Find a quiet room (soft furnishings help; avoid echoey kitchens and bathrooms).
2. Use one phone for everything, held at the same distance (about 20 cm), with the same person
   for each language.
3. Speak warmly and a little slowly, like reading to a 4-year-old. Smile – it can be heard.
4. One line per file. Leave a short breath of silence at the start and end; trim anything longer.
5. Save as **.m4a** (most phone recorders do this), or .mp3 / .ogg / .wav.
6. Name each file exactly as in the FILE column, for example `en_c7bf17e9.m4a`.

Short single sounds (a letter like "B", a syllable like "की") should be said on their own,
clearly, not as part of a sentence.

## Adding recordings to the app

Put the files in:

- `app/src/main/assets/voice/en/` for English
- `app/src/main/assets/voice/hi/` for Hindi

Then build the app again. Nothing else to change: the app finds them by name.

## When the script changes

If the games change what they say, the scripts are regenerated by running the unit tests
(`VoiceTest.writeRecordingScripts`). File names depend only on the words, so recordings you
already made keep working; only new lines need recording.
